# Voyager 1 One Light-Day Milestone

## Summary

On **18 November 2026 at 10:16:07 UTC** (NASA), Voyager 1 becomes the first human-made object one light-day (25,902,068,356 km) from Earth. This ticket adds a live countdown across the Voyager pages, a short explainer page `/voyager-light-day`, Revision 3 of `/voyager-story`, and switches the `/facts` light-time from Sun distance to Earth distance.

Started from two reader-shared items (`PDSL_Ideation/Voyager/`, local only): a news screenshot (verified accurate against NASA's 29 Oct 2026 post) and a social carousel (captions true; slides 1–6 AI-generated and scientifically inaccurate, slide 7 is NASA's PIA23645). Neither is used on the site.

**Sources:** NASA, *What Is a Light-Day?*; NASA Voyager blog, 29 Oct 2026; NASA Voyager FAQ; JPL Horizons (target −31, observer 500@399).

## Architecture

| Component | Implementation |
|-----------|---------------|
| **Milestone constant** | `ONE_LIGHT_DAY_UTC`, `LIGHT_DAY_AU` in `voyager1_project/voyager1_position_model.py` (single source of truth, ADR-002) |
| **Earth range** | `earth_range_au()` / `voyager1_earth_distance_au()`: model heliocentric distance along Voyager's RA/Dec, minus Earth's position from low-precision solar coordinates. Used by `_voyager1_live_stats` for light-time on `/` and `/facts` |
| **Countdown** | `templates/_light_day_banner.html`, included on `/`, `/facts`, `/voyager-story`, `/voyager-light-day`. Server renders days/hours and the before/after state from the `light_day` context global; inline JS ticks seconds and flips state at the target time. No `innerHTML`; both messages are pre-rendered and toggled |
| **Explainer page** | `GET /voyager-light-day` renders `templates/voyager-light-day.html` (static) |
| **Figure** | `Images/voyager1_light_day.png` and `_large.png`, generated by `voyager1_project/voyager1_light_day.py` from cached Horizons data (`voyager1_project/data/voyager1_horizons_2026_2028.csv`, summary JSON alongside) |
| **Story text source** | `docs/the-voyager-story.md` mirrors `templates/voyager-story.html`; both carry the revision history |

## Checked Findings (JPL Horizons, daily, 2026–2027)

| Finding | Value |
|---------|-------|
| NASA milestone (geometric Earth distance) | 18 Nov 2026, 10:16:07 UTC |
| Earth one-way light-time first reaches 1,440 min (signal arrival) | 19 Nov 2026, ~02:18 UTC |
| Sun distance reaches one light-day | ~4 Feb 2027 |
| Post-crossing minimum light-time | 1,441.4 min on 24 Apr 2027 (1.4 min above a light-day; never recrosses) |
| Model vs Horizons | Earth offset within 0.02 AU; radial model ~0.11–0.15 AU behind (rate 3.6 vs 3.56 AU/yr) |

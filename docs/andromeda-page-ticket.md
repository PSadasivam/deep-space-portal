# Andromeda Deep Research Page

**Issue:** [#21](https://github.com/PSadasivam/deep-space-portal/issues/21)

## Summary

Add `/andromeda` under Deep Research: a story-first page presenting the reproduced Milky Way-Andromeda merger forecasts (Sawala et al. 2025: 52%; Wu et al. 2026: 90%) and announcing a dated forecast before Gaia Data Release 4 (2 December 2026).

This is the first public surface of the Andromeda research. It shows only results that passed Stage 1 validation and labels them as reproductions, not new predictions.

**References:** `docs/andromeda-research-plan.md` (story beats, stages, milestones); sibling repository `andromeda-research` (model, runs, `docs/reproduction-log.md`).

---

## Architecture

| Component | Implementation |
|-----------|---------------|
| **Page route** | `GET /andromeda` renders `templates/andromeda.html` (static; no API) |
| **Figures** | `Images/andromeda_futures.png` (inline) and `Images/andromeda_futures_large.png` (enlarged view), generated by `andromeda-research/scripts/plot_tracks.py` from committed runs |
| **Numbers** | Hard-coded from `andromeda-research/runs/*/summary.json` (Stage 1, 28 October 2026) |
| **Enlarged view** | Lightweight lightbox, inline JS; the link falls back to opening the large image if JS is off |
| **Explainers** | Native `<details>` elements: no JS, accessible by default |

## Content Rules

- Every number must trace to a run summary or a cited source. Claims still on the research plan's "Documentary Claims to Verify" list (e.g. Andromeda's star count) stay off the page until verified.
- Report physical years on the page; code units stay in the research repository.
- No fixed Earth-habitability deadline until a climate source is selected (research plan, Topic 5).

---

## Security

Static page with no user input and no external scripts. The lightbox only reads the `href` of a fixed, server-rendered link, and the image route already rejects path traversal (`..`, leading `/`). No new dependencies.
